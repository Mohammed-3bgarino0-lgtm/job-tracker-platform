# 🏛️ معمارية مشروع قدّم | Qaddem AI (Enterprise Monorepo Architecture)

```text
قدّم | Qaddem AI
├── apps/web          منصة Next.js والملف الوظيفي وقواعد البيانات
├── apps/extension    إضافة Chrome واستخراج وتعبئة النماذج
├── packages/shared   الأنواع وقواعد التحليل المشتركة
├── prisma            مخطط قاعدة البيانات (24 نموذجاً)
└── docs              المعمارية وخطة التنفيذ
```

## 📜 القواعد الأساسية الـ 8 للمشروع:
1. **قاعدة صفر بيانات وهمية (Zero Dummy Data):** يمنع مطلقاً التكهن أو كتابة إيميلات أو أرقام افتراضية.
2. **لا ادعاء بتكامل غير مختبر:** كل كود مكتوب يعمل ومجرب بشكل مباشر.
3. **الموقع لا يقرأ X أو LinkedIn مباشرة:** الإضافة هي التي تقرأ الصفحة المفتوحة عند المستخدم.
4. **الإضافة تقرأ DOM الصفحة المحملة والمستقلة.**
5. **لا تجاوز لـ CAPTCHA أو OTP أو نفاذ.**
6. **لا ضغط تلقائي على زر الإرسال النهائي.**
7. **كل قيمة مستخرجة قابلة للمراجعة اليدوية والتعديل.**
8. **تسجيل كافة العمليات الحساسة في سجلات AuditLog.**
