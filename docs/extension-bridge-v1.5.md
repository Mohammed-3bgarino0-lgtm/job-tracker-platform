# Website–Extension Bridge v1.5

## النطاق

يضيف هذا الإصدار فوق v1.4:

- معاينة نتائج الفحص داخل نافذة الإضافة بدل عرض العدد فقط.
- تصدير النتائج كملف `.xls` متوافق مع Microsoft Excel وباتجاه RTL.
- فتح صفحة `/devices?import=last` ونقل آخر فحص عبر الجسر للمراجعة داخل الموقع.
- جمع روابط الصور العامة المرتبطة ببطاقات الوظائف مع استبعاد الصور الزخرفية والصور الشخصية الصغيرة.
- تشغيل OCR بعد ضغط المستخدم فقط، وبحد أقصى 6 نتائج و4 صور لكل نتيجة.
- جلب الصور من الخادم مع فحص البروتوكول والنطاق وعناوين الشبكات الخاصة والحجم ونوع الملف.
- تحليل الصور عبر Gemini من الخادم فقط؛ لا يُكشف المفتاح داخل الإضافة.

## الخصوصية

- لا تُرسل الصور تلقائيًا.
- لا تُقرأ الكوكيز أو كلمات المرور أو رموز الجلسة.
- لا تُرسل ملفات محلية أو صور خاصة؛ تُرسل روابط صور HTTP/HTTPS العامة المكتشفة في بطاقة الوظيفة فقط.
- النتائج تبقى محلية أو في جلسة صفحة الموقع حتى تكتمل المصادقة وموافقة الحفظ الدائم.

## حدود OCR

- يتطلب `GEMINI_API_KEY` في بيئة Railway.
- الحد الأقصى للصورة الواحدة 4MB.
- الأنواع المقبولة: JPEG وPNG وWebP وGIF.
- لا تُستخدم الصور لاختراع مسمى أو شركة أو مدينة؛ الحقول غير المقروءة تبقى فارغة.

## التصدير

يحتوي ملف Excel على المسمى، الشركة، المدينة، الوصف، بيانات التواصل، روابط التقديم والمصدر، المنصة، عدد الصور، حالة OCR، النص المستخرج، وتاريخ الاكتشاف.
