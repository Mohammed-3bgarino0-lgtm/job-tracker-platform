# قدّم AI — Chrome Extension v1.4

إضافة Manifest V3 تربط موقع قدّم بصفحات الوظائف التي يفتحها المستخدم.

## البناء

```bash
pnpm --filter @qaddem/extension typecheck
pnpm --filter @qaddem/extension test
pnpm --filter @qaddem/extension build
```

ينتج مجلد جاهز للتحميل غير المضغوط داخل:

```text
apps/extension/dist
```

## التثبيت المحلي

1. افتح `chrome://extensions`.
2. فعّل **Developer mode**.
3. اضغط **Load unpacked**.
4. اختر `apps/extension/dist`.
5. افتح صفحة `/devices` في موقع قدّم وأعد تحميلها.

## نموذج الأذونات

- الجسر يعمل فقط على نطاقات موقع قدّم الموجودة في العقد المشترك.
- فحص أي نطاق خارجي يحتاج إذنًا منفصلًا يطلبه المستخدم من نافذة الإضافة.
- `activeTab` يُستخدم لفحص الصفحة الحالية بعد ضغط المستخدم على أيقونة الإضافة.
- لا تُقرأ كلمات المرور أو الكوكيز أو رموز الجلسات.
- لا يتم الضغط على زر إرسال طلب التوظيف.

## حدود النسخة

- النتائج تُعرض داخل جلسة صفحة الموقع، ولا تُحفظ في قاعدة البيانات حتى اكتمال المصادقة وموافقة الاستيراد.
- الصفحات المعتمدة على صور فقط تحتاج OCR في مرحلة لاحقة.
- تغييرات DOM في X أو LinkedIn أو أنظمة ATS قد تحتاج محولات مصدر مخصصة.
