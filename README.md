# 💚 منصة قدّم | Qaddem AI (Saudi Modern SaaS Platform & Chrome Extension)

منصة تقنية سعودية حديثة تعتمد على الذكاء الاصطناعي لمساعدة الباحثين عن عمل على رفع وإدارة ملفاتهم الوظيفية، استخراج وتدقيق إعلانات الوظائف والمنشورات (X/تويتر، لينكد إن، إنستغرام، الواتساب، البريد، الصور والـ PDF)، توليد خطابات التقديم، التقديم بالبريد التفاعلي (OAuth / SMTP) والواتساب المباشر، وتسهيل تعبئة نماذج التوظيف عبر إضافة متصفح (Manifest V3) بأسلوب آمن يتطلب موافقة ومراجعة المستخدم في كل خطوة، مع الالتزام التام بعدم تجاوز اختبارات الحماية (CAPTCHA / OTP / نفاذ).

---

## 🌟 الميزات والمعمارية الرئيسية (Key Architectural Features)

1. **🇸🇦 الهوية البصرية والتنسيق:** تصميم سعودي تقني حديث باللون الأخضر الزمردي الداكن (`#065f46`), خلفيات رمادية فاتحة، خط `Tajawal` العربي، ودعم كامل ومزدوج للـ RTL والـ LTR.
2. **📄 استخراج ومراجعة السيرة الذاتية:** استخراج 25+ حقلاً مع إظهار نسبة الثقة (Confidence Score) ومصدر النص (Snippet Source) وشاشة مراجعة إلزامية للتعديل والحذف والتأكيد.
3. **📧 التقديم من إعلان أو منشور (Social & Ad Scraper):** سحب الإعلانات من المنشورات والصور (OCR) ومقاطع النص، واستخراج البريد ورقم الواتساب ورقم مرجع الوظيفة ومسؤول التوظيف.
4. **🛡️ شاشة المراجعة الحصريّة للبريد (Pre-Send Review Screen):** استعراض المرسل منه، البريد المستلم، CC/BCC، العنوان، نص ה-HTML المنمق، المرفقات وحجمها، مع فحص وتنبيه النطاقات المشبوهة أو غير المطابقة لنطاق الشركة.
5. **🧩 إضافة المتصفح (Chrome Extension Manifest V3):** زر **"حفظ في قدّم"** لالتقاط المنشورات، Generic Form Adapter، ولوحة جانبية SidePanel لمراجعة وتأكيد التعبئة.
6. **📊 متتبع الطلبات (Kanban Board):** تتبع منظم عبر 11 حالة محددة (مقترحة، تم التقديم، تحت المراجعة، مقابلة، عرض وظيفي...).
7. **🗄️ قاعدة بيانات ضخمة ومحكمة (Prisma ORM - 45+ Tables):** تغطي كافة الكيانات والرسائل ومحولات المواقع والـ Audit Logs.

## 🛠️ التشغيل والربط (Installation & Setup)

### 1. إعداد البيئة وقاعدة البيانات المحليّة:
```bash
# تثبيت التبعيات
npm install

# توليد عميل Prisma لقاعدة البيانات 45+ جداول
npx prisma generate

# تشغيل بيئة التطوير
npm run dev
```

### 2. التشغيل عبر Docker Compose:
```bash
docker-compose up -d
```

### 3. إعداد إضافة Chrome (Manifest V3):
1. افتح `chrome://extensions/` وفعّل **Developer mode**.
2. اضغط على **Load unpacked** واختر مجلد `extension/`.
3. اضغط زر **📌 حفظ في قدّم** العائم على أي صفحة إعلان وظيفي!
