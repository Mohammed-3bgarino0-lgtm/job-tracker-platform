# 🏛️ المعمارية التقنية والتنفيذية لمنصة قدّم | Qaddem AI Architecture Document

## 1. نظرة عامة على النظام (System Overview)

منصة **قدّم | Qaddem AI** هي منصة تقنية سعودية لمساعدة الباحثين عن عمل على رفع سيرهم الذاتية، تحليل وإدارة الملفات الوظيفية، استخراج وتدقيق إعلانات الوظائف والمنشورات من مختلف المنصات (X/تويتر، لينكد إن، إنستغرام، الواتساب، البريد، الـ PDF، الصور ولقطات الشاشة باستخدام OCR)، توليد خطابات التقديم، والتقديم التفاعلي بالبريد الإلكتروني والواتساب، بالإضافة إلى إضافة متصفح (Manifest V3) لتسهيل تعبئة نماذج التوظيف بحضور وموافقة المستخدم الصريحة.

```
+-----------------------------------------------------------------------------------+
|                                 Qaddem AI Platform                                |
+------------------------------------------+----------------------------------------+

|                                API / Server Actions                               |
+-----------------------------------------------------------------------------------+
|                        Core Services & Processing Engines                         |
|   +-------------------+  +------------------+  +-------------------------------+  |

|   | PostgreSQL Database (45+ Prisma Maps) |  | Encrypted S3 Object Storage    |   |
|   +---------------------------------------+  +--------------------------------+   |
+-----------------------------------------------------------------------------------+
```

## 2. المكونات المعمارية الأساسية (Core Architecture Modules)

### 2.1 Next.js 14 App Router & Unified SaaS Web Client
- **دعم اللغة والجهات:** دعم مزدوج وكامل للغة العربية (RTL) والإنجليزية (LTR) بناءً على خط `Tajawal`.
- **التصميم:** تصميم سعودي تقني باللون الأخضر الزمردي الداكن (`#065f46`), خلفيات فاتحة رمادية، ومكونات بطاقات واضحة.
- **الأمان:** تشفير البيانات الحساسة عبر AES-256، نظام Rate Limiting، CSP Headers، حماية من CSRF، وسجل audit logs لكافة التغييرات.

### 2.2 محرك تحليل وتدقيق السير الذاتية (CV Parsing & Confidence Review Engine)
- دعم ملفات PDF و DOCX والصور.
- استخراج 25+ حقلاً وظيفياً (الاسم، الجوال، المدينة، المسميات، الخبرات، المؤهلات، المهارات، اللغات، الراتب المتوقع، قابلية التنقل).
- احتساب **نسبة الثقة (Confidence Score)** وتحديد **مصدر النص (Source Snippet)** لكل قيمة.
- **شاشة مراجعة إلزامية:** تتيح للمستخدم التعديل، الحذف، والتأكيد قبل اعتماد أي بيان.

### 2.3 محرك تحليل وتدقيق الإعلانات والمنشورات (Job Ad & Social Leads Engine)
- يستقبل الإعلانات من: رابط، نص، صورة/لقطة شاشة (OCR)، ملف PDF، مشاركة من إضافة المتصفح، إعادة توجيه البريد، والإدخال اليدوي.
- يستخرج البيانات الوظيفية وسحابة وسائل التواصل (الإيميلات، أرقام الجوال والواتساب، رقم مرجع الوظيفة، مسؤول التوظيف، المستندات المطلوبة).
- شاشة مراجعة الإعلان وإظهار تنبيهات تعدد الإيميلات أو الأرقام لاختيار الصحيح قبل الإرسال.

### 2.4 محرك مكافحة الرسائل المزعجة وتوثيق الإرسال (Anti-Spam & Delivery Engine)
- فحص النطاقات المشبوهة والتحقق من تطابق بريد الجهة المستلمة مع نطاق الشركة الداخلي.
- تحديد سقف الإرسال اليومي وتحذير المستخدم عند تكرار الإرسال لنفس العنوان.
- شاشة المراجعة النهائية (Pre-Send Review Screen) للإيميل لاستعراض المرسل، المستلم، CC/BCC، العنوان، المرفقات وحجمها الكلي قبل الموافقة.
- تتبع حالة البريد في 10 حالات مختلفة (مسودة، مجدول، تم الإرسال، تم استلام رد...).

### 2.5 إضافة المتصفح (Chrome Extension Manifest V3 & Generic Adapter)
- تكتشف حقول الاستمارات وقوائم الاختيار والتواريخ.
- تتضمن زر **"حفظ في قدّم"** لالتقاط إعلانات التوظيف عند تصفح المنشورات.
- تعمل عبر `SidePanel API` لتعرض للمستخدم مراجعة الحقول والموافقة الصريحة قبل التعبئة.
- **التزام حظر تام:** لا تتجاوز اختبارات الحماية (CAPTCHA / OTP / نفاذ)، لا تنفذ التقديم التلقائي دون زر المستخدم، ولا تخزن كلمات مرور المواقع الخارجية.

## 3. معايير قواعد البيانات والحماية (Database & Security Standard)

- قاعدة بيانات PostgreSQL مهيكلة بـ 45+ جدولاً عبر Prisma ORM.
- عزل تام لبيانات كل مستخدم، وإتاحة زر التصدير الفوري أو الحذف النهائي للحساب والملفات.
- عدم استخدام بيانات السير الذاتية لأغراض التدريب دون موافقة مستقلة وصريحة.
